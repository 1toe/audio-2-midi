# Audio a MIDI

La web transcribe pistas aisladas en el navegador y usa un servicio Python para separar canciones completas. El servidor devuelve voz, bajo y resto para transcribir las pistas seleccionadas.

Lee [AGENTS.md](AGENTS.md) antes de editar. Ahí están las reglas del repositorio para ramas, versionado y validación.

- [Registro de avances](docs/registro-avances.md) para retomar desde el último SHA confirmado en GitHub.
- [Backlog](backlog/) para elegir historias y tareas, y registrar el estado de implementación o validación.
- [Changelog](CHANGELOG.md) para consultar qué incluye cada versión y el commit que la fija.
- [Producto](docs/01-plan-de-producto.md), [arquitectura](docs/02-arquitectura.md), [historias](docs/03-historias-de-usuario.md) y [casos de uso](docs/04-casos-de-uso.md) para el alcance técnico.
- [Checks de calidad](docs/06-checks-y-calidad.md) para cerrar las fases con evidencia.

Al cerrar una tarea, actualiza el backlog, el changelog si afecta la versión y el registro con el SHA completo verificado. En el resumen puedes mostrar el SHA corto con enlace al commit exacto.
