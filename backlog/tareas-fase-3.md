# Tareas · Fase 3 · Pulido

Objetivo: que CU-05 funcione y que CU-02 sume el piano roll. Duración estimada: 1 semana.

## H9 · Ajustar la sensibilidad y regenerar

- [ ] T3.1 Controles de umbral de notas y duración mínima.
- [ ] T3.2 Botón Regenerar que recalcula las notas desde la salida guardada del modelo, sin correrlo de nuevo.
- [ ] T3.3 Botón Restablecer con los valores iniciales.
- [ ] T3.4 Conservar el resultado anterior cuando el nuevo no tiene notas.

## H10 · Limpiar las notas

- [ ] T3.5 Decidir cómo se detecta el tempo. Es una decisión técnica abierta.
- [ ] T3.6 Cuantizar las notas al tempo.
- [ ] T3.7 Limitar las notas a las 88 teclas del piano, notas MIDI 21 a 108.
- [ ] T3.8 Fundir notas repetidas muy seguidas.
- [ ] T3.9 Un interruptor por cada limpieza. Con las tres apagadas el MIDI es igual a la transcripción directa.

## H11 · Ver las notas en un piano roll

- [ ] T3.10 Dibujar las notas por tiempo y altura.
- [ ] T3.11 Cursor que avanza con la reproducción.
- [ ] T3.12 Tocar un punto mueve la reproducción a ese momento.

## Cierre de la fase

- [ ] T3.13 Repetir el set completo y comparar las notas con las de las fases 1 y 2.
- [ ] T3.14 Prueba con tres personas que no conocen el proyecto: suben un audio y bajan el MIDI sin ayuda.
- [ ] T3.15 Revisar la definición de terminado para H9 a H11.
